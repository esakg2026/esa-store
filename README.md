# ESA Store — магазин бренда ESA

Интернет-магазин коллекции **ESA Black Series 2026** + Telegram-бот магазина + приложение владельца.
DREAM · CREATE · ACHIEVE — «Стиль. Технологии. Будущее.»

- Сайт: https://esa-store.onrender.com
- Бот: https://t.me/esa_store_kg_bot
- Приложение владельца (заказы, статусы, статистика): https://esa-store.onrender.com/admin/ — ключ входа: `ADMIN_TOKEN` из файла `.env` на компьютере (в интернете его нет)

## Что нужно сделать владельцу

1. **Цены** — в файле `products.json` у каждого товара поле `"price": null`. Впишите число в сомах, например `"price": 2500`. Пока `null` — на сайте написано «Цену уточняйте». Можно также вписать сумму к оплате в самом заказе (в приложении /admin или в боте командой `/sum ESS-123456 4500`).
2. **Фото** — сейчас стоят **временные** картинки, вырезанные из рекламных макетов (`public/img/p/`). Нужны реальные фото товаров (лучше 4:5, от 1000×1250, формат .webp или .jpg). Положите файл в `public/img/p/` и впишите имя в `images` товара.
3. **Наличие** — `"inStock": false` = «Под заказ»; `"soldOut": ["XS", "XXL"]` — размеры, которых нет.
4. **Доставка** — точные тарифы не указаны (их нет в открытых источниках). Сейчас менеджер сообщает стоимость при подтверждении. Тексты — в `public/app.js` (функция `pageDelivery`).

После правки файлов: сохранить → `git add -A` → `git commit -m "цены"` → `git push`. Render пересоберёт сайт за 1–3 минуты.

## Как устроен заказ
1. Клиент: каталог → размер/цвет → корзина → оформление (имя, телефон, город, доставка/самовывоз, адрес, комментарий). Или «Купить в 1 клик» (имя + телефон). Или прямо в боте.
2. Владельцу в Telegram приходит карточка заказа с кнопками: ✅ Подтвердить · 💳 Оплачен · 🚚 Отправлен · 🎉 Получен · ❌ Отменить.
3. Клиент видит статус на странице заказа (ссылка с секретным ключом или номер заказа + телефон) и получает сообщения в боте, если подключил Telegram.
4. **Реквизиты** (MBank/Optima, `PAY_INFO`) клиент видит **только после подтверждения** заказа.

Команды владельца в боте: `/orders`, `/o ESS-123456`, `/sum ESS-123456 4500`. Ответить клиенту — ответ (reply) на его сообщение или карточку заказа.

## Техника
- Node 22+, без фреймворков. `server.mjs` — сервер, `api/` — заказы, каталог, бот, админка, `lib/` — общая логика, `public/` — сайт.
- База: Neon Postgres (та же, что у esa-orders), но свои таблицы: `store_kv`, вид `store_orders_view`.
- Защита: экранирование HTML, CSP-заголовки, лимиты запросов, ловушка для спам-ботов, секрет webhook, проверка товаров/размеров/цветов на сервере.
- Секреты — только в `.env` (не в git) и в переменных Render. Шаблон — `.env.example`.
- Логотип: `public/brand/esa-logo.svg` (вектор, белый), `esa-logo-black.svg`, `esa-logo-current.svg` (цвет текста).
- Исследование UX магазинов: `research.md`.
